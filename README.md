# 大肥鱼桌宠 · PySide6 版

一个跑在 Windows 桌面上的小女仆桌宠。**PySide6 重写**，透明无边框窗口，逐帧 WebP 动画，
带光标跟随倾斜、拖拽 Q 弹、单体模式碰撞推挤。

## ★ 这是一个独立程序，不是 DSH 的附属功能

**桌宠本体完全独立运行，不依赖 DeepSeek Harness。** 装好 PySide6 直接 `python main.py`
就能跑，不需要安装 DSH、不需要任何 AI 服务、不需要联网。

DSH 插件（`dsh-plugin/`）只是**可选外挂**：装上之后桌宠能读到 Harness 的工作状态
（干活时切动作、闲时碎碎念、显示余额）。**不装插件，桌宠的所有本地玩法一个不少**；
装了插件，DSH 也只是"给桌宠送事件的人"，桌宠进程始终独立于 DSH 存活 ——
DSH 关掉、重开、崩溃，桌宠都照常待在桌面上。

同理，本项目与 DeepSeek 官方无隶属关系，也不属于 Harness 插件市场的一部分。

---

## 它长什么样

- 640×360 的原生帧（WebP 序列）1:1 贴在透明窗口上，不做二次缩放 —— 旋转时也不掉清晰度
- 106 个动作、25 400 帧，按分类加权随机播放；移动动作会真的走到新位置
- 群体模式：10 只一起，靠 Boids 分离/聚合/朝向 + 二维逃避自己散开
- 单体模式：多只之间**不会重叠**，撞上就推着走，顶到屏幕边缘整串停下

## 功能

| 功能 | 说明 |
|---|---|
| **光标倾斜摇晃** | 鼠标在附近移动时，角色以脚底为轴左右倾斜（±3.5°、±5px）+ 水平位移，弹簧收敛，鼠标静止时保持当前倾角不抖 |
| **拖拽 Q 弹** | 拖着走时沿运动方向拉伸，松手弹一下；单击只弹不拉伸 |
| **单体碰撞** | AABB 硬碰撞 + 推箱子求解：撞人者前进、被撞者被顶走、被撞到墙则整条链一起停；拖拽和物理飞行中豁免 |
| **群体模式** | 多开十只，Boids 涌现散开；和单体模式互斥 |
| **漫游开关** | 关掉后移动类动作变成"原地跑步"（动画照播、不位移），并禁止切到群体模式 |
| **摇晃 / 置顶 / 开机自启** | 右键菜单里三个开关，点击即时生效 |
| **DSH 联动**（可选） | 装上 `dsh-plugin/` 后，插件把 Harness 的 `session/event` 转发给桌宠，驱动工作状态动画；余额、碎碎念气泡。**不装插件不影响任何本地功能** |

## 独立性怎么保证的

三条硬边界，代码里都成立：

1. **零 import 依赖**：`src/` 里没有任何一行 import DSH 的东西，桌宠不知道 DSH 是否存在
2. **单向推事件**：DSH 只通过 HTTP `POST /event` 往桌宠推事件，桌宠从不反向调用 Harness；
   推送端断开，桌宠侧只是「最近没有新事件」，照常自己玩
3. **独立进程 + 单实例**：桌宠自带 `GET /state` 探测，DSH 拉起时发现已有实例就只做事件转发代理，
   绝不复制第二只（`main.py` 的 `--mode stdio` 分支）

反过来，DSH 插件也可以随时卸载，卸载后残留的只是一个不被调用的目录。

## 环境要求

- Windows 10 / 11（用到 Win32 API 做置顶与前台唤起）
- Python 3.10+
- PySide6 ≥ 6.5（开发时用 6.12.0）

```bash
pip install PySide6
python main.py
```

就这两步。**不需要安装 DeepSeek Harness，不需要 API key，不联网也能跑。**
想让它跟 DSH 联动，再去装 `dsh-plugin/`（见下文），不装就只是个单纯的桌宠。

## 素材说明（重要）

**本仓库只是源码，不含动画素材。** 原因有二：

1. 帧素材有 834 MB（`frames/`，106 个动作 / 25 400 张 WebP），不适合放进 git；
2. 动画资源有独立的授权条款，见下节。

想跑起来需要自己准备 `frames/` 目录和 `config.jsonc`（动作池、权重、移动分级）。
程序会依次在这些位置找配置（后两个只是兼容旧安装路径的兜底，与 DSH 是否安装无关）：

```
./config.jsonc
~/.dsh/profiles/desktop/node_modules/dsh-pet/assets/config.jsonc
../backup-dsh-pet-原版/assets/config.jsonc
```

## 目录结构

```
main.py                 启动入口（含系统托盘）
config.jsonc            动作池 / 权重 / 移动分级（不在本仓库）
frames/                 帧素材（不在本仓库）
src/
  host/                 配置加载、HTTP 事件服务、日志、开机自启、技能开关
  runtime/              窗口绘制、气泡、解码线程、帧缓存
  shared/               倾斜 / Q弹 / 碰撞 / 物理 / 抽取算法（纯逻辑，不依赖 Qt）
tests/                  20 个测试文件，pytest 驱动
dsh-plugin/             【可选】DeepSeek Harness 插件（拉起桌宠、转发事件、余额）
文档/                    开发交接文档与踩坑记录
```

除 `dsh-plugin/` 外的所有代码都与 DSH 无关，可以单独拷走使用。

## 测试

```bash
python -m pytest tests/ -q
```

窗口相关测试用 `QT_QPA_PLATFORM=offscreen` 跑，不需要真实桌面。
注意 offscreen 虚拟屏只有 800×800，涉及坐标的用例要落在屏内。

## 右键菜单

```
关闭 DSH / 查看余额 / 行为：单体 / 多开一只 / 关闭所有（N）
────────────────
设置 ▸   漫游 / 摇晃 / 置顶 / 开机自启
技能 ▸   DSH拷问
大小 ▸
────────────────
动作 ▸
────────────────
退出桌宠
```

所有开关统一写法「名称：值」，点击切换（不用勾选框）。

前两项（关闭 DSH / 查看余额）和「技能 ▸」是**装了 DSH 插件才会用到的入口**，
没装 DSH 时它们要么是空操作、要么直接不显示 —— 其余所有菜单项都是纯本地功能。

## 已知限制

- 只在 Windows 上验证过
- 倾斜与 Q 弹依赖 `paintEvent` 里的复合变换，群体模式下只有主体会晃（子体保持静止，省 CPU）
- 不带素材无法开箱即跑，见上文「素材说明」
- DSH 联动只对 DeepSeek Harness 生效；换成别的编辑器/IDE，桌宠会退化成纯桌宠（这是设计如此，不是缺陷）
